# Contributing

Small bug fixes and focused improvements are welcome. For a large feature, open an issue first so its scope can be agreed.

Use the build instructions in [README](README.md). Wails bindings are generated by `script/build.sh`; do not edit them manually. Keep filesystem operations in `internal/library`, preserve raw Skill text, and keep automatically discovered sources read-only.

Test changes with disposable temporary folders and synthetic documents. Never use real credentials, personal Skill sessions or a user's originals as mutation fixtures. Translation tests use local HTTP fixtures and an in-memory key store.

Run the relevant Go package tests, frontend grouping tests when grouping changes, and the production frontend build when UI changes. The [preview workflow](.github/workflows/preview.yml) performs the shared package and runtime dependency checks.

Include the problem, resulting behavior and relevant verification in the pull request. Do not add credentials, local configuration, caches, generated app bundles or screenshots of personal catalogs. Contributions are licensed under the project's MIT license. Security problems follow [SECURITY.md](SECURITY.md).
